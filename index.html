01 / Web Application

Weather Forecast Web Application

A real-time weather web app that fetches live conditions and a multi-day forecast from a public weather API based on city search or the user's live geolocation. Built to feel instant: the interface swaps its background gradient, icon set, and copy to match current conditions — clear, cloudy, rainy, or stormy — so the weather is understood at a glance, not just read as numbers.

Under the hood it handles async API calls with loading and error states, debounced city search with autocomplete suggestions, unit toggling (°C / °F), and a "recent searches" list persisted so users can jump back to cities they've already checked. Every layout, from the current-conditions hero to the hourly scroll strip and the 5-day outlook cards, is fully responsive down to small mobile screens.

02 / Business Landing Page

Gym & Fitness Studio Landing Page

A high-energy, conversion-focused landing page for a fitness studio, designed to move a visitor from "just browsing" to booking a trial class. It leads with a bold hero and a clear call to action, followed by a class-schedule grid, a trainer roster with specialties, and tiered membership pricing cards built to make the mid-tier plan the obvious choice.

Scroll-triggered animated counters highlight member results (classes run, members trained, average rating), a testimonials carousel builds social proof, and a sticky "Join Now" bar keeps the CTA visible on mobile. The whole page is built mobile-first with vanilla JavaScript handling the interactions — no framework overhead — so it loads fast and deploys anywhere as a static site.
